# reMouse —— 手机浏览器当触摸板

电脑跑一个 Python 服务，手机浏览器打开局域网地址，就得到一块触摸板 + 键盘 + 媒体遥控。
手机端**零安装**，不需要装 App、不需要连数据线。

```
┌─────────────┐   WebSocket    ┌──────────────┐   SendInput   ┌────────┐
│ 手机浏览器   │ ─────────────▶ │ Python 服务   │ ────────────▶ │ 桌面   │
└─────────────┘   同一局域网    └──────────────┘               └────────┘
```

---

## 快速开始

```powershell
cd D:\CodeAI\quWOrk\remouse

# 用 py 或 Python 全路径启动（本机 python 不在 PATH）
py -3.11 run.py
```

终端会打印：

```
  注入后端 : win32-sendinput
  本机名称 : DesktopTz
  令牌     : 1P5…2g

  手机扫码或在浏览器输入：
    http://10.166.157.159:8765/?k=xxxxxxxxxxxxxxxxxxxxxx
```

手机连同一个 Wi-Fi，浏览器打开这个地址即可。

**第一次连接被 Windows 防火墙拦**，用管理员 PowerShell 放行一次：

```powershell
netsh advfirewall firewall add rule name="reMouse" dir=in action=allow protocol=TCP localport=8765
```

## 先自检再使用

```powershell
py -3.11 run.py --self-test
```

它会真实移动光标 60px 再还原，验证整条注入链路。**遇到"能连上但光标不动"，先跑这个。**

自检会报告三件事：进程会话、桌面会话、令牌完整性级别。任何一个不对，注入都会被系统静默丢弃（详见下文"已知限制"）。

## 手势

| 手势 | 动作 |
|---|---|
| 单指滑动 | 移动光标 |
| 单指轻点 | 左键单击 |
| 双击不抬 / 长按 350ms | 进入拖拽，移动后自动释放 |
| 双指轻点 | 右键单击 |
| 双指滑动 | 滚动（带惯性，可开关自然方向） |
| 三指上下左右 | Win+Tab / Win+D / 切窗口（**默认关闭**） |

底部工具条三个键按住即按下、抬起即释放，可以直接拖选文字和文件。

## 右侧滚动条

屏幕右边缘有一条竖向滚条，上下拖动即滚动鼠标滚轮。

- **拖动才显示滑块**：静止时只剩一条很淡的轨道，按下拖动时滑块才浮现。
- **按住不放会一直滚**：滑出一个速度后手指停住但不松开，
  就会保持那个速度持续滚动，松手立刻停止。
  滑得越快滚得越多，最快 80 行/秒，最慢保底 8 行/秒。
  这跟真实滚轮的观感一致——不用反复重复"滑一下、抬起、再滑一下"。
  巡航时滑块有呼吸动画、轨道有流动渐变，明确提示"它还在动"。
- **越远滚得越快**：倍率随拖动距离从 1 倍平滑升到 3 倍。
  居中时慢慢挪，适合精确微调；拖到边缘时同样的手部动作能滚三倍远。
  倍率超过 2.5 时滑块外圈光晕会扩大一圈，给"正在加速"一个视觉反馈。
- **松手回弹**：拇指会自动回到中间。所以可以无限往下拖，
  不像普通滚动条拖到底就卡住。
- **只占中间那条轨道**：轨道两侧的留白仍属于触摸板，
  靠边滑动移动光标不会误触。
- **可隐藏**：设置面板 →「显示右侧滚动条」。
- **可换边**：设置面板 →「滚动条在左侧」，左手持机时用。

滚动方向**不跟随**「自然滚动」开关。这是有意的：双指滑动是"推纸"隐喻
（手指往下 = 内容往上），滚动条是"拖滑块"隐喻（滑块往下 = 看到更晚的内容），
两者方向本来就相反，真实系统里也是这么处理的。

拖动时屏幕左侧会短暂浮出方向与倍率提示，例如 `↓ 3  ×1.8`。

## 键盘与遥控

- **键盘面板**：在手机输入框里打完一句，点"发送"，整句一次性落到电脑。
  逐字注入会跟手机输入法的拼音候选打架，所以设计成整句发送。
- **快捷键面板**：Ctrl / Shift / Alt / Win 可以锁定，再点字母组合。
  另有 F1–F12、方向键、PgUp/PgDn、PrtSc 等独立按键。
- **媒体面板**：播放暂停、上下曲、音量、静音。
- **演示**：就是方向键和 F5，在快捷键面板里。

## 常用参数

| 参数 | 说明 |

## 已知限制

这些不是 bug，是平台的硬限制，写在这里免得你浪费时间排查。

### 1. 管理员权限窗口收不到输入

Windows 的 UIPI 会阻止普通权限进程向更高权限窗口发送合成输入。
任务管理器、管理员 CMD、部分安装程序属于这一类。

**解法**：以管理员身份运行 `run.py`。反过来则不行——高完整性进程可以向低完整性窗口注入。

### 2. 低完整性级别的进程完全无法注入

从受限令牌（Low 完整性）启动的 Python，`SendInput` 会返回"成功送入 1 个事件"，
但事件被直接丢弃，光标纹丝不动，**没有任何报错**。
表现为"代码全对但鼠标不动"，极难排查。

正常双击打开的终端是 Medium 完整性，没问题。`run.py --self-test` 会直接把这个原因打出来。

### 3. 会话 0 里的进程无法注入

在服务、计划任务里跑的 Python 属于会话 0，没有可见桌面。
同样表现为"连得上、日志正常、鼠标不动"。

### 4. 游戏与部分 Electron 应用收不到合成输入

走 Raw Input 或带反作弊的程序（尤其是全屏独占游戏）会忽略 SendInput。无解。

### 5. 极少数老程序不认 Unicode 注入

`type_text` 用 `KEYEVENTF_UNICODE` 逐码元发送，绝大多数程序没问题。
个别只认虚拟键码的老程序可能吞字。

### 6. 手机端部分能力依赖 HTTPS

`WakeLock`（屏幕常亮）、剪贴板、**陀螺仪**等 API 需要安全上下文。本服务默认走 HTTP，
所以这些能力会优雅降级：功能照用，只是手机可能自己息屏。

体感要真正可用，二选一：

**A. 用 Chrome 并把源加入白名单**（不装证书）

1. 地址栏打开 `chrome://flags`
2. 搜索 `insecure`
3. 找到 `Insecure origins treated as secure`
4. 填入 `http://<你的IP>:8765`
5. 改成 `Enabled`，按提示 Relaunch

**B. 用 `--https` 启动**（一劳永逸）

`py -3.11 run.py --https`，手机装一次根证书。证书会在 IP 变化时自动重签，CA 不变。

> 注意：系统自带浏览器、微信/QQ 内置浏览器**没有实现 `DeviceMotionEvent`**，
> 即使配好 HTTPS 也拿不到传感器数据。体感必须用 Chrome 或 Firefox。

### 7. 单显示器与多屏

- 单屏：绝对定位直接映射到屏幕。
- 多屏：绝对坐标基于整个虚拟桌面，跨屏移动正常。

## 安全说明

这个服务能让**局域网内任何能访问该端口的设备**控制你的鼠标键盘，所以：

- 令牌是 22 位随机串，握手必须携带，错了直接 `close(4401)`。
- 检测到绑定的不是内网地址时会拒绝启动，除非显式加 `--allow-public`。
- 令牌存在 `.state/token`，重启不变，手机只需扫码一次；`--new-token` 可随时换。
- **只在可信的家庭/办公局域网使用**。不要在公司访客网络、公共 Wi-Fi、
  或做了端口映射的路由器后面开。

没做的：HTTPS（自签证书在手机上会被直接拦截，装了也用不了）、账号体系、云端中转。

## 设计要点

### 为什么不用 pynput 的鼠标移动

`pynput` 走的是 `SetCursorPos` 之类的绝对定位，且相对移动会经过 Windows
的**指针加速曲线**。实测：同样要求移动 420px，系统实际走了 602px（1.43 倍），
且倍率随速度变化（5px 是 0.8 倍，80px 是 2.4 倍）。

手机上手指滑 100px 而光标跑 240px，手感完全错乱。所以注入层自己跟踪坐标：
读当前位置 + 增量 → 换算成绝对坐标发送。**绝对定位不走加速曲线**，
实测 60 次 +7px 累积误差为 0。

### 为什么每个连接一个注入线程

`SendInput` 是阻塞调用。在 asyncio 事件循环里直接调，一次卡顿就拖住所有连接。
放后台线程，事件循环只负责收包和排队。

### 为什么合并位移、但不合并点击

手机 60–120Hz 发移动消息，网络抖动会带来突发。把一批移动合成一次 `SendInput`，
突发时不堆积。而点击、按键、文本的顺序和时点必须精确，一律不合并，
且执行前会先把攒下的位移刷出去，保证顺序正确。

### 断线安全释放

连接断开（或手机切后台）时，对仍处于按下状态的鼠标键和修饰键补发 `up`。
否则会留下一个"粘住"的 Ctrl 或按住不放的左键——这类工具最恼人的坑。
